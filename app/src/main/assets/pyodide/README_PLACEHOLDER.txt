DOSSIER À COMPLÉTER — Pyodide 0.26.4

Cette application est configurée pour charger Pyodide depuis ce dossier local.
Copie ici le contenu complet du dossier officiel `full/` de Pyodide v0.26.4.
Il faut notamment conserver pyodide.js, pyodide.asm.js, pyodide.asm.wasm,
pyodide-lock.json, python_stdlib.zip et tous les fichiers de données/paquets
fournis avec cette distribution. Ne copie pas seulement pyodide.js.

Source officielle : https://github.com/pyodide/pyodide/releases/tag/0.26.4
Distribution CDN correspondante : https://cdn.jsdelivr.net/pyodide/v0.26.4/full/

Une fois le dossier complété, supprime ce fichier README_PLACEHOLDER.txt.
Sans ces ressources, Python ne démarrera pas hors ligne.
